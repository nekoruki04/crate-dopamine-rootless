# Security Policy

## Supported Versions

| Version | Supported |
|---|---|
| 1.0.x | Yes |
| < 1.0 | No |

---

## Reporting a Vulnerability

If you discover a security vulnerability or critical issue affecting the host device's integrity:

1. **Do not create a public issue**.
2. Report the vulnerability privately via GitHub Security Advisories or by contacting the repository maintainers directly.
3. Include:
   - Specific device model (e.g. iPad Pro 11" 2018 A12X).
   - Exact iOS version (e.g. iPadOS 16.1.1).
   - Dopamine jailbreak version and configuration.
   - Proof of concept or detailed reproduction steps.
   - Potential impact analysis.

We strive to acknowledge receipt within 48 hours and provide a timeline for remediation.
