# Security Policy

## Supported Versions

| Version | Supported |
|---|---|
| 1.0.x | Yes |
| < 1.0 | No |

---

## Reporting Vulnerabilities

If you identify a security issue affecting device stability or unauthorized access:

1. Do not open a public issue.
2. Submit a private report via GitHub Security Advisories or contact the repository maintainers directly.
3. Include device model, iOS version, jailbreak version, and reproduction steps.
